# 外部資源

| 資源 | 用途 | 配布元 |
|---|---|---|
| Qwen3.5-2B | 登録タスクの選択・確認質問 | https://huggingface.co/Qwen/Qwen3.5-2B |
| 多言語MiniLM | 非LLMの指示照合比較 | https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2 |
| SmolVLA LIBERO | 画像・状態・英語標準指示から操作 | https://huggingface.co/lerobot/smolvla_libero |
| SmolVLM2 | 操作モデルの設定・トークナイザー | https://huggingface.co/HuggingFaceTB/SmolVLM2-500M-Video-Instruct |
| LeRobot v0.4.4 | 方策・前後処理 | https://github.com/huggingface/lerobot/tree/v0.4.4 |
| LIBERO | タスク・目標条件 | https://github.com/Lifelong-Robot-Learning/LIBERO |
| LIBERO assets | メッシュ・テクスチャ | https://huggingface.co/datasets/lerobot/libero-assets |
| ROS 2 Humble | 通信・監視 | https://docs.ros.org/en/humble/ |
| MuJoCo | 物理シミュレーション | https://github.com/google-deepmind/mujoco |

自作部分はプロンプト・JSON検査・ROS監視・プロセス間通信・記録・比較集計。モデルや物理エンジン自体を開発したとは主張しない。コードと資料の作成にChatGPT/Codexの支援を利用。各資源の配布条件は配布元で確認し、重みを再配布しない。
