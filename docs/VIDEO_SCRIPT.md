# ROS入力からの独立実行を比較した動画（横1920×縦1080・約2分6秒）

task 1〜9の遠回しな指示をROS 2の`/cleanup/instruction`へモデルごとに送信し、Qwen3.5-2Bと多言語MiniLMの判断からSmolVLA操作までを左右同じ時間軸に並べる。確認質問は動画に含めない。

- 0:00〜0:04：ROS入力、二つの選択方法、独立した物理試行であることを示す。
- 0:04〜1:58：task 1〜6・8〜9を各12秒、task 7を18秒。指示、モデル名、選択結果、選択処理時間、操作時間、LIBERO目標判定を枠の上に表示し、枠内に**各モデルのROSリクエストから撮影した別々の動画**を流す。
- 1:58〜2:06：Qwen3.5は正選択9/9・操作達成8/9・一貫成功8/9、MiniLMは正選択8/9・操作達成7/8・一貫成功7/9と表示する。

MiniLMはtask 4を保留し、その枠に操作動画を表示しない。task 7は両モデルとも200ステップで未達だったため300ステップで再実行したが、目標未達。他のタスクは最大200ステップ。各リクエストはseed 42、初期状態0、1試行でシーンを初期化する。両モデルが同じタスクを選んだ場合も別々のROS実行で撮影している。元の各タスク動画は1024×640。画面全体を横1920×縦1080とし、縦横比を保って各枠928×580へ縮小表示する。タスク映像の切り抜きや拡大補間はしない。選択処理時間にはモデル読み込みを含む。操作時間は別に表示する。動画はシミュレーション時間基準であり、短い操作映像の終端は静止表示する。倍速は使用せず、音声は無音。
